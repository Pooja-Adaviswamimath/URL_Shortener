# URL Shortener

A simple and user-friendly URL Shortener built using Flask and SQLite

## Features

- Generate random 6-character short URLs
- Create custom short codes
- Prevent duplicate custom codes
- Redirect short URLs to original URLs
- Track URL clicks
- View URL history
- Analytics dashboard
- Display most-clicked URL
- Delete URLs with confirmation
- Copy short URLs
- URL validation
- Responsive and clean user interface

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript
- Git & GitHub
